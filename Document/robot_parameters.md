# 小车 JSON 参数说明

配置文件：项目根目录 `robot_parameters.json`。初始值取自当前源码，不代表连接设备的实时值。文件包含当前 CFG 接口支持的全部 111 项运行参数。PlatformIO 每次构建前读取此文件，把 `value` 编入固件；上传完成后，重启也会使用这次烧录的值。

## 修改与生效

### 在上位机按比赛阶段调参

连接 ESP32 后进入“参数”页，点“一键读取”。顶部“分类”可按 `开局与扫码 → 圆盘抓取（两轮） → 粗加工（两轮） → 暂存第一层 → 暂存第二层 → 返航归位` 浏览，也可搜索名称和中文说明。同一参数会出现在多个相关阶段；例如粗加工和暂存共用 `搬运/工作区1～3`，修改一处会影响这几个阶段。

选中参数后，表格上方显示设备允许范围、用途和“新值”输入框。输入新值后点“修改并发送”或按回车，上位机会先写入，再自动回读核对。需要一次修改多项时，逐项点“暂存多项”，最后点“发送修改”。写入只对当前开机生效。确认现场调试值后点“保存为烧录默认值”，上位机会把已回读确认的当前值写入项目根目录的 `robot_parameters.json`；若仍有待发送编辑，会提示先发送并确认。下一次 PlatformIO 上传后，重启就会使用这些值。

“发送并进入主流程”会先发送待修改参数并回读确认，再发送 `SYS RELEASE`。该操作进入主流程的 WAIT_START 阶段，仍需设置启停区，并在准备完成后发送 `SYS START`；它不会直接启动行驶。固件要求在 Debug 模式、停止视觉对齐且机械动作空闲时写入参数。若写入或回读失败，页面不会发送 RELEASE。

### 调完参数立即试动作

在对应比赛阶段选中参数并填新值，选择“当前阶段试动作”，点击“应用参数并试动作”。上位机先执行 CFG 写入并回读确认，只有一致时才发送动作指令；失败时不执行动作。完成后可继续修改、再次试动作。“试选中机械臂轴”按所选位置的高度、伸出、转台或夹爪值只移动该轴，适合逐项核对方向和位置；它不执行完整抓放步骤。

| 比赛阶段 | 可选试动作 | 现场条件 |
| --- | --- | --- |
| 开局与扫码 | 开局机械臂姿态、底盘小距离移动 | 机械臂和底盘活动范围清空 |
| 圆盘抓取（两轮） | 试单轴、圆盘抓取一件、DISC 视觉定位 | 单件抓取时选颜色和目标载物台；圆盘有料，目标台为空 |
| 粗加工（两轮） | 试单轴、三件放到工作区、三件从工作区取回、WORK_AREA 定位 | 放料前载物台有料；取回前工作区有料、载物台为空 |
| 暂存第一层 | 试单轴、三件放到工作区、三件从工作区取回、WORK_AREA 定位 | 与粗加工共用三个工作区位姿，小车停在暂存区才会对准暂存区物料 |
| 暂存第二层 | 试单轴、三件码垛第二层、三件从工作区取回、WORK_AREA_LOADED 定位 | 第一层已就位，载物台有待码垛物料 |
| 返航归位 | CORNER 视觉定位、底盘小距离移动、开局机械臂姿态 | 视觉定位需机载视觉反馈；小距离移动是相对位移，不代替完整返航路线 |
| 底盘导航与标定 | 底盘小距离移动 | 输入车身坐标 X/Y/转角和轮速；节点坐标只有主流程路径导航才使用 |

三件搬运试动作调用固件现有 DEMO1 / DEMO2 / DEMO4，不包含底盘导航；物料位置必须与当前停车区域对应。页面对“停止视觉定位”发送本次开启模式的停止请求。调试指令的 ACK / ISSUED 表示接令或已下发，DEMO 的 DONE 表示动作序列结束；它们都不是实物抓取成功或机械轴实际到位的反馈。

### 直接修改 JSON 后烧录

1. 用编辑器打开 JSON，只修改对应条目的 `value` 数字，保留参数名称。`description` 是中文说明，`minimum` / `maximum` 是参考范围，`integer` 表示是否为整数。
2. 若要永久使用这些值，直接在 PlatformIO 执行 Build / Upload。上传成功后启动上位机，在“参数”页点击“一键读取”，核对设备回读的值。OTA 上传同样会写入新的固件默认值。
3. 若只想临时调试而不烧录，启动 `python upper_computer.py`，连接串口，在 Debug 模式下停止视觉对齐，等待机械动作结束。
4. 打开“参数”页，点击“一键读取”，再点击“导入 JSON”，选择修改后的文件。
5. 检查“待发送”列，点击“发送修改”。显示“修改已生效并回读确认”后才表示设备已应用。
6. 需要备份实车参数时点击“导出 JSON”。导出包含当前值以及已暂存的待发送修改，默认另存为 `robot_parameters_custom.json`。

仅保存 JSON 不会改变已烧录的固件；重新 Build / Upload 后才会永久更新默认值。上位机“发送修改”只改小车 RAM，重启后恢复为最近一次烧录时的 JSON 值。导入文件不执行机械动作。`value: null` 不编入固件，使用对应源码默认值。

导入成功会替换已有待发送编辑；校验失败则保留原编辑。可删除不想导入的条目，只保留部分参数；`value: null` 表示跳过该项。未知参数、重复名称、非数值、非有限值、越界值会被拒绝。实际范围以设备固件注册值为准，改文件中的范围不能解除固件限制。JSON 不支持 `//` 注释。

例如把圆盘抓取高度从 150 mm 改为 145 mm：

```json
"搬运/圆盘/高度(mm)": {
  "value": 145,
  "description": "圆盘抓取时的升降高度",
  "minimum": 0,
  "maximum": 175,
  "integer": false
}
```

这是文件中的一个条目片段，请在原文件中修改。

## 各部分对应什么

| JSON 分组 | 数量 | 作用 |
| --- | ---: | --- |
| 搬运 | 27 | 7 个作业位置各 3 个坐标，以及安全高度、层高、速度、夹爪开合角度和等待时间 |
| PID | 12 | 视觉 X、视觉 Y、角度三个控制器，各有 Kp、Ki、Kd、积分限幅 |
| 对齐 | 16 | 五种视觉场景各有 X/Y/角度死区，以及共用的最大轮速 |
| 底盘 | 7 | 节点导航平移速度/加速度、转向速度/加速度、扫码接近/往返轮速，以及旧位置接口的停车等待 |
| 标定 | 5 | X/Y 平移、底盘旋转、机械臂升降/伸缩的脉冲换算系数 |
| 地图 | 50 | 0～24 号节点各自的场地 X/Y 坐标 |

## 机械臂位置和抓放动作

| 位置 | 高度 mm | 伸出 mm | 转台 deg | 对应动作 |
| --- | ---: | ---: | ---: | --- |
| 圆盘 | 150 | 50 | 90 | 圆盘抓取物料 |
| 载物台1 | 102 | 20 | 242 | 小车自身的 1 号载物台 |
| 载物台2 | 102 | 20 | 271 | 小车自身的 2 号载物台 |
| 载物台3 | 102 | 21 | 300 | 小车自身的 3 号载物台 |
| 工作区1 | 2.5 | 61 | 48 | 粗加工区或暂存区的 1 号位置 |
| 工作区2 | 2.5 | 0 | 86 | 粗加工区或暂存区的 2 号位置 |
| 工作区3 | 2.5 | 39 | 125.3 | 粗加工区或暂存区的 3 号位置 |

高度控制 5 号升降电机，伸出控制 6 号伸缩电机，二者以开机清零位置为绝对原点。转台是 2 号总线舵机，夹爪是 1 号总线舵机。工作区参数由粗加工、暂存流程共用，不能分别设置两套位置。

公共动作参数：

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| 安全高度(mm) | 170 | 到目标上方、抓起后、放下后抬升使用的高度 |
| 二层高度增量(mm) | 60 | 每增加一层增加的高度；二层高度为基础高度+60，三层为基础高度+120 |
| 速度 | 250 | `MoveArm` 的公共速度输入；升降/伸缩驱动速度为输入×3，舵机时间参数为 `(300-输入)×10`，不是统一的 mm/s |
| 夹爪张开(deg) | 50 | 抓前张开、放置松手角度 |
| 夹爪夹紧(deg) | -5 | 抓取夹紧、搬运持物角度 |
| 等待时间(ms) | 1000 | 步骤基础等待时间，不是实测到位判定 |

当前固件动作顺序：

- 到目标上方：升降至安全高度并设置伸出长度、夹爪角度，等待两次基础时间；再转向目标角度，等待一次基础时间。
- 抓取：张开到目标上方 → 降到目标高度（等待 1.5 倍）→ 夹紧（等待 1 倍）→ 抬到安全高度（等待 1.5 倍）。
- 放置：夹持到目标上方 → 降到放置高度（等待 1.5 倍）→ 张开（等待 1 倍）→ 抬到安全高度（等待 2 倍）。

JSON 调整这些步骤使用的参数，不支持新增步骤、重排步骤或单独设置每一步的速度/等待倍数。对应实现见 `src/material_transfer.cpp`。

升降范围为 0～175 mm，伸出为 0～170 mm；叠层后的总高度也必须不超过 175 mm。转台目标范围为 -180～360 度，固件在允许范围内选择最近的等效方向。转台和夹爪不要填写 -1：固件把 -1 当作“保持不动”的特殊值。范围通过只表示数值合法，安全高度和夹爪角度仍应按实车标定。

## 视觉 PID 和对齐

| 控制器 | Kp | Ki | Kd | 积分限幅 |
| --- | ---: | ---: | ---: | ---: |
| 视觉X | 0.01 | 0.0005 | 0 | 200 |
| 视觉Y | 0.01 | 0.0005 | 0 | 300 |
| 角度 | 0.03 | 0.0005 | 0 | 20 |

Kp 乘以当前误差，Ki 乘以累计误差积分，Kd 乘以误差变化率。“积分限幅”限制累计积分本身，发生在乘 Ki 之前。控制输出限于 -1～1，再用于合成底盘轮速。这是 ESP32 的视觉闭环 PID，不是张大头电机驱动器内部的位置环或速度环 PID。

五种场景共用以上三组 PID，但分别使用死区：

| 场景 | 含义 | X死区 | Y死区 | 角度死区 deg |
| --- | --- | ---: | ---: | ---: |
| DISC | 圆盘整体对齐 | 8 | 8 | 0.5 |
| DISC_MATERIAL | 圆盘单个物料对齐 | 3 | 3 | 0.2 |
| WORK_AREA | 工作区对齐 | 3 | 3 | 0.2 |
| WORK_AREA_LOADED | 载物工作区对齐 | 3 | 3 | 0.2 |
| CORNER | 角点/归位对齐 | 6 | 6 | 0.4 |

X/Y 的单位沿用视觉端的误差输出，不能默认当作毫米；角度单位为度。死区越大，允许的剩余误差越大。`对齐/最大轮速(RPM)` 默认 20，只控制视觉 PID 对齐的速度上限。

## 运动标定和地图

| 参数 | 默认值 | 对应换算 |
| --- | ---: | --- |
| X脉冲每毫米 | 13.3 | 底盘 X 平移距离 → 电机脉冲 |
| Y脉冲每毫米 | 13.6 | 底盘 Y 平移距离 → 电机脉冲 |
| 旋转脉冲每度 | 51.8 | 底盘旋转角度 → 电机脉冲 |
| 升降脉冲每毫米 | 80 | 机械臂升降高度 → 电机脉冲 |
| 伸缩脉冲每毫米 | 30.2 | 机械臂伸出长度 → 电机脉冲 |

相同指令距离下，系数越大，发送的脉冲越多。`底盘/停车稳定时间(ms)` 默认100，仅用于旧位置运动接口；H30节点导航改为按零轮速后的惯性安静窗口接续，不使用该固定等待值。

### 参数页修改正式节点路径速度和加速度

更新固件后，在参数页“一键读取”，阶段选择“底盘导航与标定”，搜索“节点导航”：

- `底盘/节点导航速度(mm/s)`：10～1600，可填小数，默认1200；底层按Y脉冲/mm转换成RPM，不将毫米每秒直接当轮速。
- `底盘/节点导航平移加速度(mm/s²)`：1～4000，可填小数，默认1600；用于有限位置目标下的软件轮速爬升/制动，不是驱动器0～255档位，也不保证实车加速度精确等于设定值。
- `底盘/节点导航转向速度(°/s)`：10～240，默认150；替代之前固定20°/s的限速。
- `底盘/节点导航转向加速度(°/s²)`：30～720，默认360；与平移加速度独立。四项默认及上限均已翻倍，可填小数。

停车并停止视觉对齐后修改、发送，等待“回读确认”。新值在下一条完整节点路径启动时生效，路径中途不变。对应参数也显示在圆盘、粗加工、暂存和返航阶段。独立试跑的轮速与加速度仍由试跑面板单独填写。

发送只修改RAM，重启恢复烧录默认值。需永久保留时，先发送并回读确认，再点“保存为烧录默认值”，重新编译上传。烧录后完整回读并核对Profile日志，避免导入旧配置又恢复400/200的慢速设置。速度与加速度须逐档实车验收，默认提速值不代表已验证载物稳定性。正式导航要求驱动位置/转速/状态反馈；H30为可降级辅助，不可用时不因此中断。

地图坐标单位为毫米，原点在场地左下角，X 向右、Y 向上；上位机显示会旋转，不能按屏幕方向直接理解场地轴。节点是 0～24 的蛇形编号，由底到顶为 `0~4`、`9~5`、`10~14`、`19~15`、`20~24`。修改地图坐标影响按节点导航使用的目标位置。

## 目前仍由固件控制的参数

以下不属于当前 CFG 注册表，不放入可导入 JSON，修改时仍需改源码并重新编译上传：

| 参数/行为 | 当前值或位置 |
| --- | --- |
| 视觉反馈超时 / 自动对齐总超时 | 同文件的 300 ms / 15000 ms |
| 启停区、圆盘区、粗加工区、暂存区航向 | 同文件的 180 / 90 / 270 / 180 度 |
| 扫码接近距离 / 扫描距离 / 速度 / 重试数 | `src/main.cpp` 的 900 mm / 400 mm / 60 RPM / 3 |
| 抓放步骤顺序和各步等待倍数 | `src/material_transfer.cpp` |
| 单次手动动作的速度、加速度等指令字段 | 上位机相应操作面板与串口命令；本文件不是手动动作脚本 |

运行参数定义来源：`src/runtime_parameters.cpp`、`src/chassis.cpp`、`src/material_transfer.cpp`、`src/robot_runtime.cpp`。
