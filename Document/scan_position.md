# 导航到扫码节点

Nano 在雷达扫描完成后发送 `{CMD,SYS,START}`。启停区 1 以节点 4、启停区 2 以节点 0 向 Nano 请求到节点 2 的路径。Nano 用 `{CMD,NAV,ROUTE,首节点,...,2}` 回传节点序列。小车从雷达准备动作结束时的估算位置和航向起步，转到首段道路航向，再横移到道路中心。沿道路方向的偏差计入首段剩余直行距离。例如 4→5→14 先横移到这条路的 X 坐标，再沿 Y 方向行驶。

开始执行路径时，按预计抵达航向设置扫码舵盘。路径末段为 7→2 时，终点航向指定为 270°。

| 抵达航向 | 舵盘角度 |
| --- | --- |
| 0° | 90° |
| 90° | 180° |
| 180° | 270° |
| 270° | 0° |

导航全程监听扫码。无效帧会被跳过，有效任务码保留到节点 2。到达时有有效码就继续，否则等待 1 秒。仍未识别时，料盘围绕扫码角依次摆到 +20°、回中、−20°、回中，最多五轮。舵机每段行程为 250 ms，期间持续监听扫码。收到有效任务码后，料盘完成当前动作、回中并归零，再开始节点 2→14 的导航。五轮结束仍无有效码时进入现有 `SCAN_FAILED` 状态。
