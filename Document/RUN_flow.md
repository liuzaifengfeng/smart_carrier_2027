# 小车运行流程

核对日期：2026-10-21。当前实现为 `main.cpp` 的 RuntimeCompetition 适配器、`competition_flow.h` 的非阻塞业务编排及 `motion_executor.cpp` 的单运动任务。架构、完成策略、计时和验收见 [统一运动执行](motion_executor.md)。本文取代旧版阻塞函数调用流程说明。

## 两轮顺序

| 状态 | 执行内容 | 推进条件 |
| --- | --- | --- |
| WAIT_START | 起始收臂，等待选区，共用雷达姿态作业，等待 SYS START | 启动许可；雷达失败保留原有继续开局行为 |
| READ_TASK | 起始姿态；预置有效任务码则跳过扫码，否则接近与往返扫码 | 得到有效任务码且运动作业结束 |
| GRAB_ROUND1 | 扫码节点→圆盘；look2；DISC 对齐；look3；依任务顺序抓三件 | 每次真实成功才登记物料和推进进度 |
| PLACE_COARSE1 | 圆盘→粗加工；look；WORK_AREA 对齐；依位置码放第一层 | 整组三件完成 |
| PLACE_TEMP1 | 原有 10 ms 阶段间隔；粗加工取回三件；粗加工→暂存；look；WORK_AREA；放第一层 | 取回完成才离开，放完才进入第二轮 |
| GRAB_ROUND2 | 暂存→圆盘；look2；DISC；look3；第二轮顺序抓取 | 同首轮，每件后恢复观察并等新识别会话 |
| PLACE_COARSE2 | 圆盘→粗加工；look；WORK_AREA；放第一层 | 整组完成 |
| STACK_TEMP2 | 取回三件；粗加工→暂存；look；WORK_AREA_LOADED；放第二层 | 使用原二层高度增量，整组完成 |
| RETURN_HOME | 起始收臂；按开局锁存区号返航；转向及 look4；CORNER；归位动作 | 路径、观察、对齐及归位均完成 |
| DONE | 停止总定时器，输出正式计时结果，通过运动任务关闭电机使能 | 保持结束状态 |

两轮粗加工放料后均直接取回，不额外开启 WORK_AREA_LOADED。前往圆盘使用 look2，DISC 对齐结束后的 look3 保留实测转台 90°±5°、1500 ms 超时；前两件抓完都需重新准备观察姿态，清理串口积压和跨边界半帧后接受新识别。

扫码保留连续 700 mm 接近加 400 mm 搜索，以及最多三次交替 400 mm 往返；二维码/手动任务码均可提前结束搜索。位移更新使用原编码器换算。手动预置码不确认车辆实际位于扫码节点，操作方仍须保证首条路径起点正确。

## 状态与完成

主循环每 10 ms 推进一次，提交后仅查询同一作业。底盘 Runner 与机械臂 Sequence 由单个工作任务逐次推进；同步兼容函数供旧调用者使用，不进入正式业务或串口解析路径。可选末段观察提前展开默认关闭，开启后仍需底盘、机械臂两者完成才能启动视觉。

物料记录在对应抓放序列末端提交，失败不会提前登记或跳过整组；整组三件中已经完成的单件仍保留其实际软件记录。普通抓取检查任务顺序和空载物台；FORCE_GRAB 绕过业务顺序、占用时警告，但不推进自动进度。ACK/REQUESTED 均不算完成，等待 DONE/FAILED。DONE 表示软件完成条件满足，仍不证明物料真实夹住或底盘无打滑。

观察姿态、九组正反向搬运配方、线缆边界、H30 校角与原有定位判定保留。当前默认机械臂依原等待完成，反馈模式需实车核验后显式启用；`currentArm` 是目标值。

## 路径、视觉与恢复

正式路线请求沿用 ROUTE_REQUEST/ROUTE 回传，允许等待路径期间继续接收路径和维护查询；路径起止不匹配返回既有失败。节点位置控制继续使用停车转向与共线合并，有限位置反馈不能证明世界坐标无打滑。独立试跑也使用同一执行器。

DISC、WORK_AREA、WORK_AREA_LOADED、CORNER 的 PID 和原有对齐条件保留。串口收到最新 ALIGN_DATA 后只更新队列，由运动任务计算并发令；既有 15 秒对齐超时保留。

扫描、路径、对齐、搬运分别返回已有失败状态；不自动续跑、不新增永久锁或参数错误锁死。NAV STOP、试跑 STOP 及 OTA 请求取消旧作业，停止等待与后续发令，保留夹爪。已完成单件不会因取消回滚。

总任务定时器沿用原 3000000 ms（50 min）配置；其回调保持总超时停车及暂停主任务语义，不代表 180 秒赛项验收。OTA 等待动作停止后更新，失败恢复后旧作业不继续，维护串口/OTA 不因一般参数错误永久关闭。故障补光由 `loop()` 周期更新，播放 1.4 秒三连爆闪和渐强光效，故障解除后恢复设定亮度。

## 计时与现场验收

SYS START 被主任务接受后输出 RUN_START；完整归位后输出 RUN_RESULT。PHASE、FLAG、SPAN、STEP、RESULT 记录业务和动作区间，使用 [统计脚本](../scripts/summarize_motion_log.py) 汇总。失败或缺少结束事件时保留不完整记录，不补算成绩。

当前仅完成软件回归与编译，未验证实际总线时序、载物干涉、夹持成功率、停车位置和三分钟成绩。按 [验收阶段](motion_executor.md#计划验收边界) 先测基线与两轮一致性，再启用反馈、提前展开和物理参数优化。
